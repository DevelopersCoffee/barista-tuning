slm

High-performance Edge Intelligence platform, model-neutral decision engine (Laya + Jev), vector search, intent classification, and Rust runtime workspace.

✨ AI Agent Skill Prompt (`skill.sh` compatible)
Run `cargo check --workspace`

Edge Intelligence Architecture

🎯

edge-decision

Zero-dependency std-only decision contract supporting Choice, Score, and Boolean evaluation over structured state in a single pass.

⚡

edge-runtime & Registry

Execution planner with DecisionBackendRegistry resolving Laya, Jev, and deterministic rule backends with automated escalation routing.

🛠️

edge-compiler & DDL

Domain Description Language compiler emitting Domain IR, schema specifications, and immutable knowledge packs.

🔍

edge-search & edge-intent

Local vector retrieval engine and zero-latency intent parser running entirely on edge hardware without cloud dependencies.

⚙️

edge-kernel & edge-pack

Boring kernel lifecycle primitives, event bus, and tamper-proof ZIP pack contract verification.

📱

edge-ffi & edge-cli

Cross-platform FFI bindings for mobile/desktop (Android, macOS, Apple Silicon) and command-line compilation utilities.
