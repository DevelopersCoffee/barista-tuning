# ADR 0009: Engineering Principles

## Status

Accepted

## Decision

The platform follows these principles:

- Compiler first.
- Read-only packs.
- Separate knowledge from state.
- Zero domain logic in the kernel.
- Data-driven behavior.
- Stable public contracts.
- No global state.
- Dependency injection.
- Test by contracts.
- Defined performance and memory budgets.
- Backward compatibility through explicit versions.

## Rationale

These principles keep Edge Intelligence reusable across media, restaurants,
retail, banking, healthcare, manufacturing, and IoT.
